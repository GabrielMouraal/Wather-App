# Weather App 🌤️

Aplicação web de clima desenvolvida com HTML, CSS e JavaScript.
O projeto permite buscar informações climáticas de uma cidade por meio de uma interface simples e intuitiva.

## 🔎 Sobre o projeto

O **Weather App** é uma aplicação criada para praticar conceitos de desenvolvimento front-end, como estruturação de página, estilização com CSS, manipulação do DOM e uso de JavaScript para tornar a página interativa.

A ideia do projeto é permitir que o usuário pesquise uma cidade e visualize informações relacionadas ao clima, como temperatura e condição climática.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📁 Estrutura do projeto

```bash
Weather-App/
├── index.html
├── style.css
└── script.js
```

## ⚙️ Funcionalidades

* Campo de busca para pesquisar uma cidade
* Exibição de informações climáticas
* Manipulação de dados com JavaScript
* Interface estilizada com CSS
* Organização do projeto em arquivos separados

## 🎯 Objetivo do projeto

O principal objetivo deste projeto foi praticar:

* Estruturação de páginas com HTML
* Estilização de interfaces com CSS
* Manipulação do DOM com JavaScript
* Organização de código em arquivos separados
* Criação de uma aplicação web interativa

## ▶️ Como executar o projeto

Clone este repositório:

```bash
git clone https://github.com/GabrielMouraal/Weather-App.git
```

Acesse a pasta do projeto:

```bash
cd Weather-App
```

Abra o arquivo `index.html` no navegador.
